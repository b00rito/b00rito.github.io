This appendix belongs to the post
[Talking through the walls: WebKit IPC and how to find messages]({% post_url 2026-10-17-f3_talking_through_the_walls_webkit_ipc %}).
It lists every WebKit IPC interface in the macOS Safari 18.5 source, tag
`WebKit-7621.2.5.11.8`, grouped by direction. The tag has 216 interfaces
with 3413 messages, 262 of them synchronous. The tables were generated by
`ipc_map.py` [1], and every message of every interface is in
Appendix B [2].

Each table covers one direction. **Source** is the process that sends and
**Destination** is the process that receives and handles the messages.
**Messages** gives the number of messages the interface accepts.  **Defined
in** is the interface's `*.messages.in` file, relative to `Source/WebKit`.
An interface with more than one direction appears in the table of each and
its notes name the other processes with "also from" or "also to".

The **Notes** column uses these labels:

- **stream** marks an interface whose messages go through a shared-memory
  stream instead of one by one over the connection.
- **non-Apple ports** marks an interface that is only built for the GTK,
  WPE or Windows ports.
- **testing only** marks an interface of the IPC testing API.
- **observed send sites** means the interface has no direction annotations,
  so its sources are the processes whose code sends its messages.
- **manual** gives the reason for a direction we checked by hand in the
  code.

When the notes say nothing about the direction, the interface is annotated
with `DispatchedFrom` and `DispatchedTo`, either at this tag or on WebKit's
main branch.
